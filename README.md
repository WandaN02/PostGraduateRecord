# PostGraduate Record-Keeping System

## Project Overview

The Postgraduate Record-Keeping System is a web-based application developed to help manage postgraduate student records and academic processes.

The system provides a centralised platform for managing student information, research proposals, ethics applications, progress reports and dissertation submissions.

## Technologies Used

- C#
- ASP.NET MVC
- Entity Framework
- SQL Server
- HTML5
- CSS3
- JavaScript
- jQuery

## Main Features

- **Student Management:** Manage postgraduate student information and profiles.
- **Proposal Management:** Create and manage research proposals.
- **Ethics Applications:** Manage research ethics applications.
- **Progress Reports:** Submit and monitor postgraduate research progress.
- **Supervisor Management:** Support supervisor assignments and student supervision.
- **Evaluation Management:** Manage research evaluations and assessments.
- **Dissertation Management:** Manage final dissertation submissions.
- **User Management:** Support different system roles and access.

## Project Structure

The application follows the ASP.NET MVC architecture:

- **Models:** Handle application data and business entities.
- **Views:** Provide the user interface.
- **Controllers:** Handle application requests and operations.

## Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/WandaN02/PostGraduateRecord.git
   ```

2. Open the solution in Visual Studio.

3. Configure the SQL Server connection string in your local configuration.

4. Restore the required NuGet packages.

5. Configure your API credentials using secure environment variables. Do not commit API keys or passwords.

6. Build and run the application using Visual Studio.
